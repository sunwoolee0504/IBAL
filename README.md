# IBAL GitHub Pages

This folder is a minimal GitHub Pages project page for:

**Interaction-Breaking Adversarial Learning Framework for Robust Multi-Agent Reinforcement Learning**

## How to publish at `https://sunwoolee0504.github.io/IBAL`

1. Create or open the GitHub repository named `IBAL`.
2. Upload `index.html` and the `assets/` folder to the root of the repository.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, set:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
5. Click **Save**.
6. Wait 1–3 minutes and open:

```text
https://sunwoolee0504.github.io/IBAL
```
